# AI チャット

API キーを入れたときだけ動きます。キーがなければ、どこにも通信しません。

- **対応するサービス**: Claude（Anthropic API）、ChatGPT（OpenAI API）、OpenCode、OpenCode Go、Cursor（Cursor の CLI `agent` を使います）。モデルと effort（考える深さ）はチャットの「設定」で選べます
- **API キー**: OS のキーチェーン（macOS のキーチェーン、Windows の資格情報マネージャー、Linux の Secret Service）に保存します。データベースにもエクスポートの zip にも入りません。環境変数（`ANTHROPIC_API_KEY`・`OPENAI_API_KEY`・`OPENCODE_API_KEY`・`CURSOR_API_KEY`）でも渡せます
- **タスクの操作**: AI は、タスク・ワークスペース・担当者の一覧と作成、タスクの書き換え・移動・コメントができます。タスクの削除は、実行の前に確認が出ます
- **GitHub のリンク**: メッセージに GitHub のリンク（issue、プルリクエスト、ファイル、コミット、リポジトリ）を書くと、`gh` コマンドで中身を取ってきて AI に渡します。`gh` がなければ、公開されているものを GitHub の API から取ります
- **Slack のリンク**: メッセージに Slack のメッセージへのリンク（`https://〜.slack.com/archives/…`）を書くと、[Slack CLI](https://docs.slack.dev/tools/slack-cli/) の `api conversations.replies` で、そのメッセージとスレッドの返信（100 件まで）を取ってきて AI に渡します。トークンは Slack CLI が環境変数 `SLACK_USER_TOKEN` から読み、このアプリは保存しません。呼ぶコマンドは `slack-cli` です。macOS と WSL の中では、`slack-cli` がなければ `slack` を呼びます。macOS と Linux ではログインシェルの設定（PATH と環境変数）を読み、Windows では `slack-cli` がなければ WSL の中のものを呼びます
- **GitHub のアカウント**: `gh` にログインしているアカウントを起動のときに読み、AI に伝えます（入力は要りません）。`gh` の設定を読むだけで、設定に名前がなく API キーがあるときだけ `gh api user` で GitHub に聞きます。Windows では、WSL の中の `gh` も読みます。チャットの「設定」に今のアカウントが出て、横のボタンで読み直せます
- **GitHub の定期チェック**（標準はオフ）: チャットの「設定」でオンにすると、未完了のタスクに書かれた issue とプルリクエストのリンク（1 回に 30 件まで）を、選んだ間隔（15 分〜3 時間）で見に行きます。前回から変化があったときだけ AI を呼び、指示（書き換えられます）に沿ってタスクを更新します。定期チェックからは、タスクの削除とコマンドの実行は行いません。覚えておくのは、リンクごとの短い値だけです
- **新しいタスクを整える**（標準はオン。API キーがなければ動きません）: タスクを作るか、タスクに新しい GitHub か Slack のリンクを書くと、AI がリンクを読んで、タイトルと説明を整えます。整えている間は、タスクの行と上のバーの AI ボタンで印が回ります。ここからは、タスクの削除とコマンドの実行は行いません。「設定」でオフにできます
- **コメントから進捗を更新する**（標準はオン。API キーがなければ動きません）: タスクにコメントを書くか書き直すと、3 秒待ってから AI がコメントを読み、進捗・状態・期限・開始日・優先度を更新します。タイトルと説明は変えません。詳細の「進捗」の横のボタンで、AI が変えたところを元に戻せます。進捗は一覧にも棒と数字で出ます。「設定」でオフにできます
- **いつも AI に伝えること**: 「設定」に前提や指示を書いておくと、チャットでも、新しいタスクを整えるときでも、毎回 AI に渡ります（4000 文字まで）。ワークスペースの設定の「AI に伝えること」（2000 文字まで）は、そのワークスペースを開いている間、全体の分に続けて渡ります
- **会話の一覧**: 会話は 30 件まで残り、チャットの上の時計のボタンから開き直せます。タスクの詳細の AI のボタンで、そのタスクについての会話を開けます
- **自動の実行**: タスクの整理やコメントからの更新は会話に混ぜず、動いている間だけ入力欄の上に出ます。失敗は消すまで赤く残り、やり直せます。結果はタスクの「AI の記録」と、メニューの「AI の実行履歴」（50 件まで）に残ります
- AI には、今見ている画面（ワークスペース、一覧に出ているタスク、開いているタスク、選んでいるタスク）も伝えます
- **シェル**: チャットの横のターミナルです。AI がコマンドを実行するときは、先に確認が出ます。入力行に自分でコマンドを打つこともできます（`cd` で移動、↑↓ で履歴）。色はコマンドの出力どおりに出て、長い行は幅で折り返します。`Ctrl + C` で実行中のコマンドを子プロセスごと止め、`Ctrl + L` で画面をクリアします。`vim` や `claude` のように画面全体を使うコマンドは、同じ場所の「＋」で開く[ターミナル](terminal.md)で動かせます
- **オート実行**（標準はオフ）: 「設定」でオンにすると、コマンドの実行とタスクの削除を確認なしで行います。オンの間は、チャットの上に「オート実行」と出ます。定期チェックには適用されません
- **ウィンドウ**: チャットもシェルも別ウィンドウに切り離せ、元の場所に戻せます
- **ディスク**: 会話とシェルの出力はメモリの中だけに置き、ディスクには書きません。シェルの表示は 4,000 行まで、AI に渡す出力は 20,000 文字までです
