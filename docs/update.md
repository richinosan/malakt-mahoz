# 自動アップデート

GitHub Releases から入れたアプリで動きます。ソースからビルドしたものでは動きません。

- 起動したときと、そのあと 6 時間ごとに、GitHub Releases の最新のリリースを見に行きます。見に行く先はここだけです。つながらなければ、次の回に見に行きます
- 今より新しい版があれば、この OS 用のファイルを裏で取ってきて、同じリリースの `SHA256SUMS` と合うことを確かめます。合わなければ捨てて、画面に出します
- 最後のウィンドウを閉じたとき（終了のとき）に、新しい版に入れ替えます。次に起動すると新しい版です。取ってきてある間は上のバーにボタンが出て、押すとその場で入れ替えて起動し直します
- macOS は `.app` ごと、Windows と Linux は実行ファイルを入れ替えます。アプリを置いた場所に書き込めないとき（管理者しか書けないフォルダーなど）は入れ替えられず、次の起動で画面に出します。その版は見送り、次の版でもう一度試します
- macOS で、ダウンロードしたフォルダーから動かしているときは入れ替えられません。「アプリケーション」フォルダーへ移してから使ってください
- 取ってきた新しい版は、データベースの隣の `update` フォルダーに 1 つだけ置き、入れ替えたら消します
- アプリを 2 つ同時に動かしていても、取ってくるのと入れ替えるのは片方だけです（`update` フォルダーの隣の `update.lock` で順番を決めます）
- 右上の歯車の「設定」の「アップデート」で無効にできます。無効にすると、取ってきた版を消し、どこにも見に行きません。今動いている版は、歯車のメニューのいちばん下に出ます
