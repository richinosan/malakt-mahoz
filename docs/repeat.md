# 繰り返しのタスク

週次定例の報告や日報のように、決まった間隔でするタスクに使います。

## 付け方

タスクの詳細の「繰り返し」を押すと、その場でメニューが開きます。

- なし / 毎日 / 平日 / 毎週◯ / 毎月◯日 / 毎年◯/◯
- 間隔: 2 日ごと、2 週間ごと、3 か月ごとなど
- 曜日（毎週のとき）: 何曜でもいくつでも
- 時刻: 次の回を作る時刻（標準は 0:00）

曜日・日付は、タスクの開始日（なければ期限、どちらもなければ今日）から始まります。繰り返しのあるタスクは、一覧のタイトルの下に印が出ます。

## 次の回

時刻が来ると、そのタスクを写した次の回を作り、繰り返しは新しい回へ移ります。

- 写すもの: タイトル、説明、優先度、担当者と役、カテゴリ、URL、ワークスペース、一緒に表示するワークスペース、期限の通知の設定、サブタスク（100 件まで）
- 状態は未着手、進捗は 0% に戻ります。開始日と期限は、回の日に合わせて同じ日数だけずれます（時刻はそのまま）
- 前の回はそのまま残ります。完了にしていなくても、次の回は作られます
- 作った人は「繰り返し」として変更履歴に残ります
- 繰り返しを付けたとき・変えたときには回を作りません。次の回は、時刻がまだ来ていない最初の回です
- 次の回を作る日時は、「繰り返し」の横に出ます

アプリが動いている間だけ作ります（ロック中も作ります）。アプリを閉じていた間に時刻が過ぎた回は、起動したときにいちばん新しい 1 回だけを作ります。1 つの繰り返しから 1 回に作るのは 1 つだけなので、溜まることはありません。

繰り返しを付けられるタスクは 500 件まで、間隔は 99 までです。いちばん新しい回を削除すると、繰り返しも終わります。

## AI への指示（定期実行）

繰り返しがあるタスクには、詳細の「AI への指示」に、回を作ったときに AI に頼むことを書けます（4000 文字まで）。

- 次の回を作ると、アプリの AI がその指示を実行し、結果をその回のタスクにコメントします。例: 「前の回のコメントと、ワークスペースの今週のタスクから、報告の下書きを書く」
- AI の API キーがないときは通信しません。失敗としてチャットの上とタスクの「AI の記録」に残り、そこからやり直せます
- ここからは、タスクの削除とコマンドの実行は行いません
- 待っている指示と失敗した指示は、50 件まで残します

## 元に戻す・エクスポート

- 繰り返しの変更と AI への指示の変更は、`Ctrl/⌘ + Z` で戻せます。アプリが自動で作った回は、元に戻す相手になりません（戻しても、同じ回をもう一度は作りません）
- エクスポートの zip に入ります（`data/repeats.json`）

## AI と MCP

チャットで「毎週月曜 9 時に週次報告のタスクを作って、前の週のまとめを下書きして」のように頼めます。AI と MCP のツールは `set_repeat` です。`get_task` の `repeat` に今の繰り返しと次の回の日時が入ります。
