# ロック

ロックを有効にすると、アプリを開くときと、ロックしたあとに、OS のパスキー（Windows Hello、Touch ID、fprintd）を求めます。秘密は何も保存しません。

設定は右上の歯車で開く「設定」の「セキュリティ」の「ロック」にあります。

| 項目 | 内容 |
| --- | --- |
| ロック | 有効・無効の切り替え。変えるときにパスキーを求めます |
| 自動でロック | キーやマウスの操作がないまま、この時間が過ぎたらロックします。しない / 1・5・10・15・30 分 / 1・2 時間。標準は「しない」 |
| ロック中の通知 | ロック中の OS の通知に出すもの。「タイトルを出す」（標準）か「タイトルを出さない」 |

- 「今すぐロック」は「設定」の「セキュリティ」の「ロック」、ウィンドウの上のバーの右クリックの「ロックする」、`Ctrl + Shift + L`（macOS は `⇧⌘L`）です。キーはターミナルやアプリ内ブラウザのページを見ているときも使えます（`Ctrl + L` はシェルとターミナルの「画面を消す」）
- ロックが無効なときに「ロックする」を押すと、「設定」の「セキュリティ」の「ロック」を開きます
- 操作は、アプリのどのウィンドウ（AI bot やシェルの別ウィンドウも）のキーとマウスを数えます。PC がスリープしていた時間も、操作がない時間に入ります
- ロック中も、期限の通知（[docs/notices.md](notices.md)）や完了報告などの通知は OS の通知に出ます。コメントの本文はロック中は出しません。「タイトルを出さない」にすると「新しい通知があります」だけを出します
- ロック中に通知を押すとパスキーを求め、解除したらそのタスクを開きます
- ロック中も、[GitHub の定期チェック](ai.md)は動きます。進展があれば、AI がタスクにコメントします
- AI bot からも変えられます（`lock` ツールの `set_options`）
