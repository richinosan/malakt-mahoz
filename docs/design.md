# 設計

## 構成

| クレート | 役割 |
| --- | --- |
| `crates/core`（`malakt-core`） | データとロジック。SQLite への保存、zip の読み書き、ロック、絞り込みと並べ替え、添付、通知、完了チケット。画面に依存しません |
| `crates/ai`（`malakt-ai`） | AI とのやり取り。各サービスへのリクエスト、キーの保存、AI に渡すタスク操作、GitHub の取得、コマンドの実行。画面に依存しません |
| `crates/term`（`malakt-term`） | ターミナル。開けるシェルの一覧、PTY（Windows は ConPTY）、端末エミュレーション、キーとマウスの変換。画面に依存しません |
| `crates/update`（`malakt-update`） | 自動アップデート。GitHub Releases の確認、ダウンロードと検証、実行ファイルの入れ替え。画面に依存しません |
| `crates/app`（`malakt-mahoz`） | gpui の画面。状態は `state.rs`、描画は `render.rs`、コマンドは `cli.rs`、AI チャットは `ai.rs` と `ai_view.rs`、ターミナルは `term.rs` |

画面に依存する部分を `app` に閉じ込めているので、`core` はそのままほかの画面からも使えます。

## 速さ

- 一覧は見えている行だけを描きます（仮想リスト）
- 絞り込みと並べ替えは読み込み済みのデータに対して行い、キーを打つたびにデータベースを読みません
- SQLite は WAL で開き、よく使う問い合わせはプリペアドステートメントをキャッシュします。担当者やカテゴリはタスクごとに問い合わせず、まとめて読みます
- `mise run bench` で、1 万件のタスクでの一覧・検索・エクスポートの時間を測れます。CI でも毎回実行して結果を残します

## ディスクの使い方

ディスクに置くのはデータベースと、入れ替えを待っている新しい版 1 つだけで、ログやキャッシュは書きません。

- 消したデータの跡は、アプリを閉じるときに自動で整理してディスクに返します
- 添付ファイルは、同じ中身を 1 つだけ保存し、縮むものは圧縮します。添付やタスクを消すと、中身もその場で消えます
- 添付を外のアプリで開くときの一時ファイルは、ロックしたとき・閉じたとき・次に起動したときに消します
- 既読にして 90 日を過ぎた通知と、期限の切れた完了チケットは自動で消します

## Android と iOS

gpui が公式に対応しているのは macOS・Windows・Linux です。そのため、まずデスクトップを完成させています。`core` は画面から独立しているので、gpui のモバイル対応が進んだ段階で画面を載せられる構成にしてあります。
