# ターミナル

アプリの中でシェルを開き、`claude`（Claude Code）や `vim` のように画面全体を使うプログラムもそのまま動かせます。AI チャットの横のシェルと同じ場所に、タブとして並びます。

- **開く**: シェルの上の「＋」で開きます。「＋」のとなりの「∨」でシェルを選ぶと、次の「＋」でも同じシェルが開きます。8 個まで開けます
- **選べるシェル**
  - Windows: WSL のディストリビューション、PowerShell、Windows PowerShell、コマンドプロンプト。最初は WSL（なければ PowerShell）が開きます
  - macOS / Linux: ログインシェル（`$SHELL`。macOS なら zsh）と、`/etc/shells` にあるシェル
- **タスクから開く**: タスクの詳細のターミナルのボタンで、そのタスクのターミナルを開きます。タブにはタスクのタイトルが出ます
  - ワークスペースの設定の「ターミナルのフォルダー」に書いたフォルダーで始まります（`~` はホーム。書いていなければホーム）
  - 環境変数 `MALAKT_TASK_ID`・`MALAKT_TASK_TITLE`・`MALAKT_WORKSPACE` に、タスクの ID・タイトル・ワークスペースの名前が入ります
- **MCP**: どのターミナルにも `MALAKT_MAHOZ_BIN` と `MALAKT_MAHOZ_DB` が渡るので、そこで動かす Claude Code からタスクを読み書きできます（[docs/mcp.md](mcp.md)）。WSL の中にも渡します
- **表示**: 256 色と TrueColor、太字・斜体・下線・取り消し線、全角の文字、代替画面に対応します。罫線とブロックの文字は、マスいっぱいに線を引くので、枠がつながって見えます。場所の大きさを変えると、桁と行がプログラムに伝わります
- **キー**: ターミナルにいる間は、キーはアプリのショートカットより先に、動いているプログラムに届きます（`Ctrl + C`、`Esc`、`Ctrl + L` など）。`Shift + Enter` は改行として届きます
- **コピーと貼り付け**: ドラッグで選び（ダブルクリックで単語、トリプルクリックで行）、`Ctrl + Shift + C` でコピー、`Ctrl + Shift + V` か `Shift + Insert` で貼り付けます。macOS は `⌘ + C` と `⌘ + V`。Windows と Linux では、選んでいる間の `Ctrl + C` はコピーになり、Windows では `Ctrl + V` でも貼り付けられます
- **マウス**: マウスを受け取るプログラムには、クリック・ドラッグ・ホイールがそのまま届きます。`Shift` を押している間は、アプリの側で文字を選べます
- **さかのぼる**: ホイールか `Shift + PageUp / PageDown` で、出力を 5,000 行までさかのぼれます。打つと今の出力に戻ります
- **日本語の入力**: IME で変換中の文字はカーソルの場所に出て、確定するとプログラムに届きます
- **広げる・切り離す**: シェルの上のボタンで、チャットの場所まで広げたり、別のウィンドウに切り離したりできます。どちらでもターミナルは動いたままです
- **終わるとき**: `exit` などで正常に終わったターミナルは閉じます。失敗で終わったものは、出力を読めるように残り、終了コードが出ます。タブの「×」で閉じると、動いているシェルも終わります
- **ディスク**: 出力はメモリの中だけに置き、ディスクには書きません。アプリを終わると、開いていたターミナルも終わります
