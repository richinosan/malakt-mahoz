# ターミナル

アプリの中でシェルを開き、`claude`（Claude Code）や `vim` のように画面全体を使うプログラムもそのまま動かせます。AI チャットの横のシェルと同じ場所に、タブとして並びます。

- **開く**: シェルの上の「＋」で開きます。「＋」のとなりの「∨」でシェルを選ぶと、次の「＋」でも同じシェルが開きます。8 個まで開けます
- **選べるシェル**
  - Windows: WSL のディストリビューション、PowerShell、Windows PowerShell、コマンドプロンプト。最初は WSL（なければ PowerShell）が開きます
  - macOS / Linux: ログインシェル（`$SHELL`。macOS なら zsh）と、`/etc/shells` にあるシェル
- **タスクから開く**: タスクの詳細のターミナルのボタンで、そのタスクのターミナルを開きます。タブにはタスクのタイトルが出ます
  - ワークスペースの設定の「ターミナルのフォルダー」に書いたフォルダーで始まります（`~` はホーム。書いていなければホーム）
  - 環境変数 `MALAKT_TASK_ID`・`MALAKT_TASK_TITLE`・`MALAKT_WORKSPACE` に、タスクの ID・タイトル・ワークスペースの名前が入ります
- **MCP**: ターミナルを開くと、そのシェルの Claude Code と Cursor に、このアプリの MCP サーバーが登録されます（[docs/mcp.md](mcp.md)）。`claude` や `agent` と入力するだけで、タスクを読み書きできます
  - Claude Code は `claude mcp add --scope user` と同じ登録、Cursor は `~/.cursor/mcp.json` への書き足しです。`claude` や `~/.cursor` がなければ何もしません。アプリの場所が変わると、次にターミナルを開いたときに登録し直します
  - WSL の中には `/mnt/c/...` の場所で登録します。`~/.local/bin` があれば、`malakt-mahoz` の名前で Windows のアプリを呼ぶコマンドも置きます
  - タブの右のプラグのボタンで、手でも登録できます。Claude Code と Codex は、見ているシェルで有効な登録のコマンドが入力の行に入ります（Enter で実行）。Cursor はその場で登録します
  - どのターミナルにも `MALAKT_MAHOZ_BIN` と `MALAKT_MAHOZ_DB` が渡ります。WSL 以外では、`malakt-mahoz` の名前でもこのアプリを呼べます
- **ファイルのドロップ**: ファイルや画像をターミナルにドロップすると、その場所が入力の行に入ります。空白のある場所は引用符で囲み、WSL では `/mnt/c/...` に読み替えます。Claude Code などは、画像の場所を画像として受け取ります
- **表示**: 256 色と TrueColor、太字・斜体・下線・取り消し線、全角の文字、代替画面に対応します。罫線とブロックの文字は、マスいっぱいに線を引くので、枠がつながって見えます。場所の大きさを変えると、桁と行がプログラムに伝わります
  - Nerd Font のアイコン（oh-my-posh や Starship のプロンプトの記号）は、同梱の JetBrainsMono Nerd Font Mono で描きます。PC に Nerd Font を入れていなくても、Windows Terminal と同じように記号が出ます。Powerline の三角と半円はマスいっぱいに描くので、となりの色とすき間なくつながります
- **キー**: ターミナルにいる間は、キーはアプリのショートカットより先に、動いているプログラムに届きます（`Ctrl + C`、`Esc`、`Ctrl + L` など）。`Shift + Enter` は改行として届きます
  - タブの操作と全画面は、Windows Terminal と同じキーでアプリが受けます。`Ctrl + Shift + T` で新しいターミナル、`Ctrl + Shift + W` でタブを閉じる、`Ctrl + Tab` / `Ctrl + Shift + Tab` で次 / 前のタブ、`Ctrl + Alt + 1〜9` でその番号のタブ（9 は最後）、`F11` で全画面。macOS は `⌘ + T`、`⌘ + W`、`⌘ + 1〜9`、`⌃ + ⌘ + F`
- **ブラウザのタブのキー**: Chrome や Edge と同じキーが、ページの中にいても URL の欄にいても使えます。`Ctrl + R` / `F5` で読み込み直す、`Alt + ←` / `Alt + →` で戻る / 進む、`Ctrl + L`・`Alt + D`・`F6` で URL の欄、`Ctrl + T` で新しいタブ、`Ctrl + W` で閉じる、`Ctrl + Shift + T` で閉じたタブを開き直す、`Ctrl + Tab` と `Ctrl + 1〜9` でタブの切り替え、`Ctrl + F` でページ内を検索（`Enter` / `F3` で次、`Shift + Enter` で前、`Esc` で閉じる）、`Ctrl + P` で印刷、`F11` で全画面。macOS は `⌘` で、戻る / 進むは `⌘ + [` / `⌘ + ]`
  - タブを切り替えたら、ページにキーの入力先が移り、そのままページの中でキーを使えます。設定の「キー操作」に、アプリ・ブラウザ・ターミナルのキーを分けて並べています
  - リンクのホイールクリックで開く小さなウィンドウでも、読み込み直す・戻る / 進む・ページ内を検索・印刷・全画面のキーは同じです。`Ctrl + W`（`⌘ + W`）でそのウィンドウを閉じます
- **コピーと貼り付け**: ドラッグで選び（ダブルクリックで単語、トリプルクリックで行）、`Ctrl + Shift + C` でコピー、`Ctrl + Shift + V` か `Shift + Insert` で貼り付けます。macOS は `⌘ + C` と `⌘ + V`。Windows と Linux では、選んでいる間の `Ctrl + C` はコピーになり、Windows では `Ctrl + V` でも貼り付けられます
- **マウス**: マウスを受け取るプログラムには、クリック・ドラッグ・ホイールがそのまま届きます。`Shift` を押している間は、アプリの側で文字を選べます
- **リンク**: 出力の中の `https://` で始まる URL と、プログラムが付けたリンク（OSC 8）は、`Ctrl` を押しながらクリックすると、OS の標準のブラウザで開きます（macOS は `⌘ + クリック`）。`Ctrl` を押しながらマウスを乗せると、リンクに下線が引かれ、マウスカーソルが指の形になります。行をまたいで折り返した URL も 1 つのリンクです。開くのは `http://` と `https://` の URL だけです
- **さかのぼる**: ホイールか `Shift + PageUp / PageDown` で、出力を 5,000 行までさかのぼれます。打つと今の出力に戻ります
- **日本語の入力**: IME で変換中の文字はカーソルの場所に出て、確定するとプログラムに届きます
- **広げる・切り離す**: シェルの上のボタンで、チャットの場所まで広げたり、別のウィンドウに切り離したりできます。どちらでもターミナルは動いたままです。切り離したウィンドウの名前は、見ているタブの名前になります
- **終わるとき**: `exit` などで正常に終わったターミナルは閉じます。失敗で終わったものは、出力を読めるように残り、終了コードが出ます。タブの「×」かホイールクリックで閉じると、動いているシェルも終わります（ブラウザのタブも同じ操作で閉じます）。アプリを閉じると、すべてのターミナルのシェルと、その中で動いているプログラムが終わります
- **ディスク**: 出力はメモリの中だけに置き、ディスクには書きません。アプリを終わると、開いていたターミナルも終わります
