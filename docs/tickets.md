# 完了チケット

タスクの詳細の「完了チケット」で発行し、コマンドで引き換えます。自動の処理や、アプリを開いていないときの報告に使えます。

```sh
malakt-mahoz redeem <チケット> --message "公開しました"      # 完了報告を書いて完了にする
malakt-mahoz redeem <チケット> --message-file report.md
malakt-mahoz ticket <チケット>                             # タスクを読むだけ（引き換えない）
```

- 自分の分として発行したチケットは、タスク全体を完了にします。ほかの担当者の分として発行したチケットは、その人の分だけを完了にします
- チケットの文字列は発行したときにしか表示されません。データベースには SHA-256 のハッシュだけを置きます
- 有効期間は発行から 400 日です。1 回引き換えると、もう一度引き換えても最初の完了報告が返るだけです
- チケットは、引数の代わりに環境変数 `MALAKT_MAHOZ_TICKET` でも渡せます。結果は JSON を 1 行で出し、終了コードは成功が 0、失敗が 1、使い方の誤りが 2 です
- アプリを開いたままでも引き換えられます。1 分以内に画面に反映され、ほかの人の報告は通知に出ます
