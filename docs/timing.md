# 予想工数と所要時間

タスクごとに、どれくらいかかりそうか（予想工数）を決められます。終わったタスクには、実際にかかった時間（所要時間）が出ます。ポモドーロで測る「作業時間」（[docs/pomodoro.md](pomodoro.md)）とは別のもので、所要時間は始まりから終わりまでの経過です。

## 予想工数

詳細の「予想工数」を押すと、その場に欄が開きます。

- 書いて Enter: 「1日3時間」「90分」「1.5h」「2週間」「1か月」「1:30」のように書けます。月・週・日・時間・分を組み合わせられます（週は 7 日として読みます）。数字だけなら時間です
- チップ: 15分・30分・1時間・2時間・4時間・1日・2日・3日・7日・1か月。押すとすぐ入ります
- 単位ごとの − ＋: 月・日・時間は 1 ずつ、分は 15 分ずつ
- クリア: 予想工数を外して閉じます
- 読めない書き方のときは「解釈できません」と出て、保存しません。Esc で書きかけを捨てて閉じます

並べ替えや「予想工数を超えた」の比べ方では、1 か月を 30 日、1 日を 24 時間として数えます。

## 所要時間の基準

どこから数え始めて、どこで終わりにするかは、仕事によって違います。基準は次から選びます。

| 開始 | |
| --- | --- |
| 作った時 | タスクを作った時刻 |
| 担当が付いた時 | 担当がいない状態から、担当が付いた時刻 |
| 進行中にした時（標準） | 状態を「進行中」にした時刻。「未着手」に戻すと数え直します |
| 開始日 | タスクの開始日（時刻がなければその日の 0:00） |

| 完了 | |
| --- | --- |
| 完了にした時（標準） | タスクを完了にした時刻 |
| 自分の分を完了にした時 | 担当者のうち自分の分を完了にした時刻（自分が担当でなければ、タスクを完了にした時刻） |

- 基準は「全体の標準」→「ワークスペース」→「タスク」の順に上書きできます。全体の標準は統計の画面、ワークスペースはワークスペースの設定、タスクは詳細の「所要時間」の基準のボタンで変えます。ワークスペースで決めていなければ、親のワークスペースの基準を使います
- 選んだ開始の時刻がないまま終わったタスク（進行中にしないで完了にした、など）は、進行中にした時 → 担当が付いた時 → 作った時 の順に、あるものから数えます。そのときはホバーにどこから数えたかが出ます
- 終わっていないタスクは、選んだ開始の時刻があれば、今までの経過を数え続けます
- 中止したタスクは数えません
- 進行中にした時刻と担当が付いた時刻は、タスクに残します。この機能より前に作ったタスクは、変更履歴から埋めます

## 一覧と詳細

- 詳細の「所要時間」に、所要時間と、予想工数との差（超えたら「+30分」、収まったら「−1時間」）が出ます。ホバーで数えた区間と基準が出ます
- 一覧の列に「予想工数」と「所要時間」を出せます（最初は隠してあります。列の見出しを右クリックして出します）。予想工数を超えた所要時間は赤で出ます
- 並べ替え: 予想工数が短い順、所要時間が短い順
- 絞り込み: 予想工数あり・予想工数なし・予想工数を超えた

## 統計

上のバーの統計のボタンで開きます。ワークスペースを開いているときはそのワークスペース（サブワークスペースを含む）、それ以外は全体の統計です。

- 期間: 1 週間・1 か月・3 か月・1 年・すべて（その期間に終わったタスク）
- 完了の数、所要時間の平均・中央値・合計
- 予想工数に収まった割合、予想工数の合計に対する所要時間の合計の割合
- 終わっていないタスクの数と、残りの予想工数、予想工数を超えて数えているタスクの数
- 担当者ごと、ワークスペースごと（全体なら最上位のワークスペース、ワークスペースならサブワークスペース）

## ほかの機能とのつながり

- 定時タスクと繰り返し: 雛形にも予想工数と基準を入れられ、作ったタスクにそのまま入ります
- アプリ内 AI と MCP: `create_task` / `update_task` の `estimate`（「1日3時間」か ISO 8601 の `P1DT3H`）と `time_basis`、`get_task` の `time`、`get_time_stats`、`set_time_basis`（[docs/mcp.md](mcp.md)）
- 変更履歴: 予想工数と基準の変更が残ります
- エクスポート: 予想工数は ISO 8601 の期間（`P1M2DT3H30M`）、基準は `in_process>completed` の形でタスクとワークスペースに入ります。全体の標準は端末の設定なので書き出しません
