# ポモドーロタイマー

作業と休憩を交互に測るタイマーです。最初の画面には出ません。上のバーを右クリックして「新しいウィンドウ」→「ポモドーロ」（macOS はアプリのメニューの「ポモドーロ」、または「設定」の「ウィンドウ」）で、別のウィンドウに開きます。

- タスクを選んで始めると、作業の段が終わったときに、測った時間がそのタスクの「作業時間」に残ります。タスクの詳細には、測ったことがあるタスクだけ「作業時間」（合計と回数）が出ます
- タスクを選ばずに測ることもできます。途中でタスクを変えると、それまでの分は前のタスクに残ります
- 一時停止していた間は数えません。1 分に満たない作業は残しません
- 段が終わると OS の通知が出て、ウィンドウの輪が光ります。次の段は止まったまま待ちます。「休憩を自動で始める」をオンにすると、作業のあとの休憩だけはそのまま始まります
- 決めた回数の作業が済むと、休憩が長い休憩になります
- ウィンドウを閉じても、タイマーは止まりません。アプリを閉じたときに開いていれば、次の起動で開き直します
- キー: `Space` で開始・一時停止、`Esc` でタスクの一覧や設定を閉じる

## 設定（ウィンドウの歯車）

| 項目 | 標準 | 範囲 |
| --- | --- | --- |
| 作業 | 25 分 | 1〜180 分 |
| 休憩 | 5 分 | 1〜180 分 |
| 長い休憩 | 15 分 | 1〜180 分 |
| 長い休憩までの回数 | 4 回 | 1〜12 回 |
| 休憩を自動で始める | オフ | |
| 作業を始めたときの音楽 | なし | なし / 再生 / 一時停止 |
| 休憩を始めたときの音楽 | なし | なし / 再生 / 一時停止 |

## 音楽

アプリの中に音楽を流す機能はありません。OS で再生中のメディア（Spotify、ブラウザの YouTube、offline-playlist など、どのアプリでも）を、OS の仕組みで操作します。

| OS | 使う仕組み |
| --- | --- |
| Windows | システムのメディア操作（SMTC）の、今のセッション |
| macOS | 「再生中」（Now Playing）のアプリ |
| Linux | MPRIS（D-Bus）。鳴っているプレイヤー、なければ最後に止めたもの |

- 標準では何もしません。設定で選んだときだけ、作業を始めた（一時停止から戻した）ときと、作業が終わった・休憩を始めたときに送ります
- 作業で「再生」を選んでいるときは、作業を一時停止・停止すると、音楽も一時停止します
- ウィンドウの下に、再生中の曲のジャケット・曲名・アーティスト・アルバムが出ます。ウィンドウを開いている間、2 秒ごとに読み直します。何も開いていなければ出ません
- 曲の横の ⏮ ▶ ⏭ で、前の曲・再生 / 一時停止・次の曲を手で送れます
- ジャケットは、Windows と macOS は OS から受け取った画像、Linux はプレイヤーが手元のファイル（`file://`）で渡したものだけ出します。ネットにある画像は取りに行きません
- macOS 15.4 からは、Apple 以外のアプリが再生中の曲を読めなくなっています。そのときは曲が出ません
- 操作できるメディアがないときや、OS が断ったとき、再生中の曲を読めなかったときは、ウィンドウにエラーが出ます

## データ

- タイマーの状態と設定は、データベースの設定（`pomodoro.timer`、`pomodoro.settings`）にあります。アプリの画面・AI チャット・MCP のどこから動かしても、同じタイマーです
- 作業の記録は `work_logs` の表に 1 回ずつ入ります（新しいものから 5 万件まで）。エクスポートの `data/work_logs.json` に入り、インポートで戻ります
- 作業の記録は「元に戻す」の段になりません。タスクを消して元に戻すと、記録も一緒に戻ります

## AI と MCP から

| ツール | すること |
| --- | --- |
| `get_pomodoro` | 今の段・残り時間・作業しているタスク・設定・今日の合計 |
| `pomodoro` | `start`（`task_id` でタスクを選んで始める）、`pause`、`stop`、`skip`、`set_task`、`set_settings` |
| `list_work_logs` | 作業の記録（タスクごと、日付から） |
| `open_window`（アプリの AI だけ） | `{"kind": "pomodoro"}` でウィンドウを開く |

`get_task` の `work` に、そのタスクの作業の回数と合計の秒数が入ります。
