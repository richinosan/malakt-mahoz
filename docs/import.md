# ほかのツールからの取り込み

Notion・Redmine・Backlog・ClickUp のエクスポートと、Slack のリマインダー・Slack リストのタスクを取り込めます。

## 取り込み方

- **一覧の上のインポート**（↑）: ファイルを選ぶと、中身で形式を見分けて、開いているワークスペースに入れます。このアプリのエクスポートの zip なら、今までどおり全体を戻します
- **設定の「連携と同期」**: 「連携を追加」でサービスを選び、ファイル（Slack は種類）と取り込む先（新しいワークスペースか、今あるワークスペース）を選んで「取り込む」を押します。Redmine と Backlog はサーバーの URL を入れると、チケットの URL をタスクの URL 欄に入れます
- **AI と MCP**: ツール `import_tasks`（`source` は `file`・`slack_reminders`・`slack_list`）

取り込みは 1 回の操作で、Ctrl+Z で丸ごと元に戻せます。

## 書き出し方と、読む項目

| サービス | 書き出し方 | 元の ID | URL |
| --- | --- | --- | --- |
| Notion | データベースの「…」→「エクスポート」→「Markdown & CSV」（zip のまま） | ページの ID | `https://www.notion.so/<ID>` |
| Redmine | チケットの一覧の「他の形式にエクスポート」→ CSV（説明と最新の注記も入れる） | チケット番号 | サーバーの URL を入れたとき `…/issues/<番号>` |
| Backlog | 課題の検索結果の「…」→ CSV | 課題キー | サーバーの URL を入れたとき `…/view/<キー>` |
| ClickUp | 一覧かテーブルの「…」→「Export」→ CSV（All columns） | Task ID | `https://app.clickup.com/t/<ID>` |
| Slack のリマインダー | なし（Slack CLI の `reminders.list`） | リマインダーの ID | なし |
| Slack リスト | なし（Slack CLI の `slackLists.items.list`。リストの URL を入れる） | 項目の ID | リストの URL に `?record_id=<ID>` |

- 項目: タイトル・説明・状態・優先度・担当・開始・期限・進捗・親子・カテゴリ（トラッカー、種別、タグなど）・URL・コメント
- 状態と優先度は、サービスの標準の名前（英語と日本語）で対応付けます。知らない状態は「未着手」、知らない優先度は「なし」です
- 担当は名前で、そのワークスペースで使える同じ名前の人にします。いなければ、そのワークスペースの担当者として足します
- コメントを書いた人が担当者にいれば、その人のコメントにします。いなければ、本文の先頭に名前を書きます
- 文字コードは UTF-8・UTF-16・Shift_JIS（CP932）・EUC-JP を読みます
- Notion の日付が範囲（`A → B`）なら、始まりを開始、終わりを期限にします。zip の中の Markdown のページは説明に入れます

## 重複と失敗

- 取り込んだタスクには元の ID を残し、同じものをもう一度取り込んでも新しく作りません（取り込み済みとして数えます）。消したタスクは、もう一度取り込めます
- Notion の CSV だけ（zip でない）のときは、行の中身から ID を作ります。中身が変わった行は別のものとして取り込みます
- 元の ID はエクスポートの zip（`data/import_origins.json`）にも入り、別の端末に移しても重複を見分けます
- 読めない行（日付や進捗が読めない、タイトルが空など）が 1 つでもあれば、何も取り込まずに、読めなかった行を全部挙げます

## Slack

Slack のリンクと同じく、Slack CLI（`slack-cli`）の `api` を使います。トークンは CLI が環境変数（`SLACK_USER_TOKEN` など）から読み、このアプリは持ちません（[ai.md](ai.md)）。

- リマインダーには `reminders:read`、Slack リストには `lists:read` と、担当者の名前を読む `users:read` が要ります
- Slack リストは有料プランのワークスペースだけにあります
- 「後で読む」「保存済み」は Slack の To-do に置き換わり、公開の API がないので取り込めません
