# タイマー

カウントダウンとストップウォッチの、単純なタイマーです。最初の画面には出ません。上のバーを右クリックして「新しいウィンドウ」→「タイマー」（macOS はアプリのメニューの「タイマー」、または「設定」の「ウィンドウ」）で、別のウィンドウに開きます。

- 上のバーの右の ⌛ でカウントダウン、⏱ でストップウォッチに切り替えます。切り替えると最初に戻ります
- カウントダウンは、止まっている間に時間を押すとその場で書き直せます。`Enter` かほかの場所を押すと決まり、`Esc` で取り消します。下の「1 分」「3 分」「5 分」「10 分」「30 分」でもすぐ選べます
- 書き方: `5`（5 分）、`1:30`（1 分 30 秒）、`1:00:00`（1 時間）、`1時間30分`、`90秒`。1 秒から 99 時間 59 分 59 秒まで
- ▶ で開始、もう一度押すと一時停止。↺ で最初に戻し、＋ でカウントダウンに 1 分足します（動いている間も止まりません）
- カウントダウンが 0 になると、アプリの通知（ベル）と OS の通知が出て（[docs/notices.md](notices.md)）、ウィンドウの輪が光ります。通知を押すと、タイマーのウィンドウが手前に出ます
- ストップウォッチの輪は 1 分で 1 周します
- ウィンドウを閉じても、タイマーは止まりません。アプリを閉じたときに開いていれば、次の起動で開き直します
- キー: `Space` で開始・一時停止、`Esc` で書き直しやエラーを閉じる

## データ

- タイマーの状態は、データベースの設定（`timer.state`）にあります。アプリの画面・AI bot・MCP のどこから動かしても、同じタイマーです
- 元に戻すの段にはなりません

## AI と MCP から

| ツール | すること |
| --- | --- |
| `get_timer` | 今のモード（`countdown` / `stopwatch`）・状態（`ready` / `running` / `paused` / `done`）・長さ・出している時間 |
| `timer` | `start`（`seconds` か `text` を渡すと、その長さで始める）、`pause`、`reset`、`set`（長さやモードを変える）、`add`（カウントダウンに足す） |
| `open_window`（アプリの AI だけ） | `{"kind": "timer"}` でウィンドウを開く |
