# 期限の通知

期限が近づいたタスクを、アプリの通知（ベル）と OS の通知で知らせます。知らせるのは、自分が担当のタスクと担当者のいないタスクで、未完了のものだけです。

## いつ知らせるか

右上の歯車で開く「設定」の「通知」で選びます。どれもいくつでも選べ、何も選ばなければ知らせません。

| 項目 | 選べるもの | 標準 |
| --- | --- | --- |
| 時刻つきの期限 | 期限ちょうど / 5・10・15・30 分前 / 1・2 時間前 / 1・2 日前 / 1 週間前 | 期限ちょうど |
| 日付だけの期限 | 当日 / 前日 / 2 日前 / 1 週間前 | 当日 |
| 日付だけの期限の時刻 | 0:00 / 6:00 / 7:00 / 8:00 / 9:00 / 10:00 / 12:00 / 18:00 | 9:00 |

- タスクごとに変えるときは、タスクの詳細の「通知」のメニューで選びます。「標準に合わせる」で全体の標準に戻ります。時刻つきの期限と日付だけの期限は別々に覚えるので、期限の時刻を消しても、日付だけの期限の側は標準のままです
- 通知の文は、残りの時間に合わせて「期限まであと 5 分です」「期限は明日の 18:00 です」「期限は今日です」のようになります
- アプリを閉じている間に知らせる時刻が過ぎていたら、開いたときに、そのうちいちばん新しいものを 1 回だけ知らせます。期限の日を過ぎたものは知らせません
- 期限を変えると、新しい期限で知らせ直します
- OS のリマインダーとの連携（[docs/reminders.md](reminders.md)）を使っているときは、リマインダーの通知も同じ時刻に出ます
- ロック中も OS の通知は出ます（[docs/lock.md](lock.md)）
- AI チャットと MCP からも変えられます（`get_due_alerts` / `set_due_alerts`）
- タスクごとの設定はエクスポートの zip に入り、取り込むと戻ります。全体の標準は入りません
