# 定時タスク

週次定例の報告や日報のように、決まった時刻が来るたびに新しいタスクを作ります。ワークスペースの設定で、そのワークスペースに作るタスクの雛形を決めます。前に作ったタスクは書き換えず、毎回 1 件ずつ新しく作ります（1 つのタスクを次の回へ写していくときは、[繰り返し](repeat.md)を使います）。

## 置き場所

- ワークスペースごと: ワークスペースの右クリックの「定時タスク」か、ワークスペースの設定の「定時タスク」。そのワークスペースにタスクを作ります
- 未所属: 「設定」の「AI」→「定時タスク」で、上の場所を「未所属」にします。どのワークスペースにも入れないタスクを作ります

「＋」で「新規定時タスク」が開き、そのままタイトルを書けます。行を押すと開いて、その場で変えられます。Esc で書きかけを捨てて閉じます。スイッチで止められます。

## 雛形

雛形には、タスクに入れられる項目をすべて入れられます。入れた値が、作ったタスクにそのまま入ります。

- タイトル: 作るタスクのタイトル（200 文字まで）
- いつ: 毎日 / 平日 / 毎週◯ / 毎月◯日 / 毎年◯/◯と、間隔・曜日・時刻（標準は足した日の曜日の毎週 9:00）
- URL: タスクの URL 欄に入るリンク（いくつでも。Enter か欄を離れると足します）
- 状態・優先度・進捗（0 / 25 / 50 / 75 / 100%）
- 予想工数（「1日3時間」のように書いて Enter か欄を離れると保存）・所要時間の基準（[docs/timing.md](timing.md)）。基準を選ばなければ、ワークスペースの基準
- 担当: 人ごとに役（R / A / C / I）も選べます。選ばなければ、ワークスペースの「タスク追加時の既定値」の担当
- 開始日・期限: 作った日の当日・翌日・2 日後・3 日後・1 週間後・2 週間後と時刻。期限を選ばなければ、ワークスペースの既定値の期限
- 通知: 期限があるときに、何分前・何日前に知らせるか
- カテゴリ・同期先（ほかのワークスペースと同期）・説明: 選ばなければ、ワークスペースの既定値。「ワークスペースの設定に戻す」で既定値に戻ります
- 親タスク: そのワークスペースの未完了のタスクから選びます。親タスクを削除したあとは、親なしで作ります
- サブタスク: タイトルを並べておくと、作ったタスクのサブタスクとして作ります
- 添付: ファイルを添付しておくと、作ったタスクに同じファイルが添付されます（1 件 10MB まで、50 件まで）
- AI への指示: 作ったタスクで AI に頼むこと（4000 文字まで、Shift+Enter で改行、Enter で保存）

作った人は「定時タスク」として変更履歴に残ります。

## 作るとき

- 足したとき・変えたときにはタスクを作りません。次に作るのは、時刻がまだ来ていない最初の回です。次に作る日時は、開いた行の「いつ」の横に出ます
- アプリが動いている間だけ作ります（ロック中も作ります）。アプリを閉じていた間に時刻が過ぎた回は、起動したときにいちばん新しい 1 回だけを作ります
- 止めていた定時タスクを動かすと、次の回はそのときから数えます
- AI への指示があれば、作ったタスクでアプリの AI がその指示を実行して、結果をコメントします（繰り返しの[定期実行](repeat.md#ai-への指示定期実行)と同じ）。作ったタスクは「新しいタスクを整える」には回しません
- 1 つの場所に置けるのは 50 件までです。ワークスペースを削除すると、その定時タスクも消えます

## 元に戻す・エクスポート

- 定時タスクの変更は `Ctrl/⌘ + Z` で戻せます。アプリが自動で作ったタスクは、元に戻す相手になりません（戻しても、同じ回をもう一度は作りません）
- エクスポートの zip に入ります（`data/schedules.json`、添付は `data/schedule_files.json` と `files/`）

## AI と MCP

チャットで「定例のワークスペースに、毎週月曜 9 時に週次報告のタスクを作って、前の週のまとめを下書きして」のように頼めます。「来月からこの URL も入れて」のように、雛形の項目も頼めます。AI と MCP のツールは `list_schedules` / `create_schedule` / `update_schedule` / `delete_schedule`、添付は `add_schedule_attachment` / `delete_schedule_attachment` です。
