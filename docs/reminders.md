# リマインダーとの連携

右上の歯車の「設定」の「通知」でオンにしたときだけ動きます。サーバーは使いません。

- **macOS**: 未完了のタスクを「リマインダー」アプリに入れます。ワークスペースごとにリストができ（入れ子は「冬のイベント / 会場」のような名前）、どこにも入れていないタスクは「Malakt Mahoz」のリストに入ります。期限・優先度・説明も入り、設定の「通知」で選んだ時刻（[docs/notices.md](notices.md)）に通知が出ます。最初に、macOS がリマインダーへのアクセスの許可を聞きます
- **Windows**: 標準のリマインダーアプリがないので、設定の「通知」で選んだ時刻に出る通知を Windows に予約します。アプリを閉じていても出ます。通知の見出しがワークスペースの名前になります
- タスクを変えると、リマインダーもすぐ変わります。完了は両方向で、「リマインダー」で完了にする（完了を外す）と、1 分以内にタスクにも反映されます。「リマインダー」の側でのほかの変更（タイトルや期限）は、タスクには反映されません
- タスクを中止・削除すると、そのリマインダーも消えます。「リマインダー」の側でリマインダーを消しても、タスクは消えません（未完了なら作り直されます）
- 触るのは、このアプリが作ったリマインダーとリストだけです。自分で足したリマインダーが入っているリストは消しません
- 連携を解除すると、このアプリが作ったリマインダー（予約した通知）とリストを消します。タスクはそのままです
- エクスポートの zip には、連携の設定と控えは入りません
